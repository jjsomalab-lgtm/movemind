# 心動力 AI（MoveMind AI）｜初審展示版

陪健康長輩「先關心，再陪你動」的運動陪伴網頁 APP。純 HTML5 + JavaScript，不需要安裝任何工具就能執行，手機可「加到主畫面」當成 APP 使用。

本版本為第十五屆高醫校園創新創業競賽初審展示用。功能規格與決審版開發計畫請看 `docs/SPEC.md`；交給 Antigravity 或 Codex 接手開發時，請先讓它讀 `AGENTS.md`。

## 一、部署到 GitHub Pages（免費，約 15 分鐘）

鏡頭和定位都必須在 **https 網址**才能使用，GitHub Pages 會自動提供。

1. 到 https://github.com 註冊帳號並登入。
2. 右上角「+」→「New repository」，名稱填 `movemind`，選 **Public**，按「Create repository」。
3. 在新的 repository 頁面點「uploading an existing file」。
4. 把本資料夾**裡面的所有檔案與資料夾**（`index.html`、`css`、`js`、`icons`、`docs` 等）一起拖進去，按「Commit changes」。
   注意：要拖「資料夾裡的內容」，不要拖外層資料夾本身，`index.html` 必須在最上層。
5. 進入「Settings」→ 左側「Pages」→「Branch」選 `main`、資料夾選 `/ (root)` →「Save」。
6. 等 1～2 分鐘，頁面上方會出現網址，例如 `https://你的帳號.github.io/movemind/`。
7. 用手機打開這個網址：
   - iPhone（Safari）：分享按鈕 →「加入主畫面」
   - Android（Chrome）：右上角選單 →「加到主畫面」

### 之後要更新程式

把改過的檔案再上傳一次（同名會覆蓋），並把 `sw.js` 第一行附近的 `VERSION` 改成新的名字（例如 `mm-v2`），手機重新整理兩次就會換成新版。

## 二、在自己電腦上試用

需要電腦上有 Python（大多數 Mac 已內建）：

```bash
cd movemind
python3 -m http.server 8000
```

用瀏覽器打開 `http://localhost:8000`。localhost 也算安全網址，鏡頭可以使用。

## 三、初審展示建議流程（約 40 秒）

展示前一天：

1. 用手機打開網址，進入「設定」→「載入展示資料」，畫面會出現一週的示範紀錄和花園。
2. 在**有網路**的地方先開一次「坐姿抬腿」→「開鏡頭幫我數」，讓辨識模型下載並保存在手機裡。
3. 確認手機音量、螢幕亮度、自動鎖定時間（建議改為「永不」）。

展示路徑：首頁問候 → 說說今天的心情 → 點「有點累」→ 好，開始活動 → 三題確認 → 坐姿抬腿 → 按幾下「完成一下」→ 做完了 →「動完心情比較好」→ 花園長大。最後切到「紀錄」，展示「動完心情變好」與跌倒擔心度的趨勢。

時間夠的話，再示範「散步」→「模擬路線」。室內收不到 GPS，現場請用模擬路線。

### 備案

- 鏡頭打不開：直接按「完成一下」手動計數，流程不受影響。
- 網路不穩：APP 本身已存在手機裡，可以離線打開；地圖會改畫簡易路線圖。

## 四、已知限制

- **散步記錄**：網頁 APP 在螢幕關閉或切到其他 APP 時會停止定位，散步時螢幕需保持亮著。背景記錄需要原生 APP。
- **計步**：網頁讀不到手機內建計步器，目前以 GPS 距離計算。
- **語音輸入**：Android Chrome 支援度最好；iPhone 部分版本不支援，按鈕會自動隱藏。
- **AI 對話**：本版為預先設計的回應（畫面有標示「展示模式」）。真正的 AI 串接需要後端，規劃在決審版。
- **姿勢辨識**：第一次使用需要網路下載模型（約 5 MB），側坐、下半身完整入鏡時最準確。
- **資料**：訪客模式下資料只存在這支手機的瀏覽器；清除瀏覽器資料會一起刪除。

## 五、檔案結構

```
index.html              頁面骨架
manifest.webmanifest    加到主畫面的設定
sw.js                   離線快取
css/app.css             所有樣式（字級、顏色、按鈕大小）
js/app.js               所有畫面與流程
js/content.js           活動、問題、心情回應、植物等「內容」→ 改文字只要改這裡
js/store.js             資料儲存
js/garden.js            心動綠洲規則與植物繪圖
js/pose.js              姿勢辨識
js/walk.js              散步定位與地圖
js/speech.js            語音朗讀與語音輸入
js/share.js             LINE、簡訊分享
docs/SPEC.md            規格書（含決審版計畫、心理學設計）
docs/研究構想與面試準備.md  一頁研究構想與面試問答
line/                   LINE 官方帳號整合（圖文選單、n8n 程式、AI 提示詞）
AGENTS.md               給 AI 開發工具的開發守則
```

## 七、重要聲明

心動力 AI 為健康促進與非臨床陪伴工具，不提供診斷或治療，也不是緊急救護服務。緊急狀況請撥打 119。活動與安全內容為團隊依運動醫學背景整理之初稿，正式提供給長輩使用前，須經物理治療師或醫師等專業人員確認。
