# 心動力｜色鉛筆手繪插畫生圖提示詞

> 用途：產生 App 內的大幅插畫（寵物姿勢、首頁、花園、迺台灣封面、阿福小屋）。小圖示與會動的小寵物仍用程式向量圖。
> 原則：全部原創；不要模仿特定畫家或作品；不要出現文字、商標、真實人物。

## 一、共用風格（每一張都貼在提示詞最前面）

```
Original illustration in a warm Taiwanese nostalgic editorial style: soft colored-pencil hatching with visible strokes,
light risograph halftone dots, subtle misregistration, cream textured paper background (#F5F0E4),
muted palette of sage green #607D69, deep green #355B4C, brick red #BC725F, warm ochre #C9A46A, mist blue #91A9AF,
ink grey #414641. Semi-realistic natural proportions, gentle and mature mood, NOT cartoon, NOT chibi,
no thick black outlines, no neon colors, no 3D, no glossy plastic, no gradients glow, no text, no logo, no watermark.
```

## 二、角色設定（先做一張「角色設定圖」，之後每張都拿它當參考圖，長相才會一致）

- **阿福｜台灣黑土狗（成犬，中型）**：全身黑色短毛、毛尖帶一點暖褐反光；立耳、尖吻；眼睛上方兩點黃褐色眉斑（四眼）；捲起的鐮刀尾；脖子綁一條磚紅色台灣花布領巾（小白花紋）；眼神溫和、表情友善。
- **柑仔｜橘白米克斯短毛貓**：背部和頭頂橘色帶淡虎斑紋，白色口鼻、胸口、腳掌；黃綠色眼睛；體型勻稱、表情放鬆。
- **慢慢｜台灣斑龜**：橄欖綠到褐色的龜殼，殼緣帶黃色；頭頸有明顯的黃色細條紋；神情安詳。

角色設定圖提示詞：
```
[共用風格] Character reference sheet of three original companion animals on cream paper:
(1) a black Formosan mountain dog with two tan eyebrow spots, upright ears, curled sickle tail, brick-red Taiwanese floral bandana;
(2) an orange-and-white short-haired mixed-breed cat with soft tabby stripes and yellow-green eyes;
(3) a Chinese stripe-necked turtle with olive-brown shell and yellow neck stripes.
Front view and side view of each, consistent design, plenty of empty space.
```

## 三、寵物姿勢圖（每隻 4 張，共 12 張）

規格：**正方形 1024×1024、透明背景（或純米白背景，我會去背）、角色置中、腳底留 8% 空間**。

| 檔名 | 提示詞重點（接在共用風格後面） |
|---|---|
| dog_sit / cat_sit / turtle_sit | sitting calmly, facing slightly to the left, gentle smile |
| dog_happy / cat_happy / turtle_happy | happy expression, looking up, (dog) tongue out, (cat) eyes closed smiling, (turtle) head raised |
| dog_sleep / cat_sleep / turtle_sleep | curled up sleeping peacefully, eyes closed |
| dog_walk / cat_walk / turtle_walk | walking slowly to the right, side view |

範例（阿福坐姿）：
```
[共用風格] The same black Formosan mountain dog from the reference sheet, sitting calmly, facing slightly left,
gentle smile, brick-red floral bandana, isolated on plain cream background, centered, full body, square 1:1.
```

## 五、交付給我

1. 檔案放進 `img/pets/`（寵物）與 `img/scenes/`（場景），格式 PNG 或 WebP 都可以，我會壓縮成手機適合的大小。
2. 確認圖是團隊自己生成的，並保留生成紀錄（日期、使用的工具），日後若有授權疑問可以出示。
3. 放好後，在 `js/pet.js` 的 `PET_ART` 填上檔名，App 就會自動改用插畫；沒有的姿勢會自動退回向量圖。
