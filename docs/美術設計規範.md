# 心動綠洲｜美術設計規範

完整視覺版本見 `tools/character_sheet.html`（用瀏覽器開啟可列印成 PDF）。

## 造型語言
- 圓潤、無尖角；葉靈以圓形花心為臉，花瓣環繞，手腳是小葉子。
- 描邊使用同色系深色，不用純黑；柔和漸層加左上高光，接近繪本插畫。
- 表情固定：大眼睛帶反光、腮紅、小嘴微笑。

## 色彩
| 用途 | 色碼 |
|---|---|
| Primary Forest Green（主色、按鈕） | #164F43 |
| Sage Green（卡片底、選中狀態） | #E7F0E7 |
| Warm Ivory（背景） | #F7F5EC |
| Warm Amber（獎勵、重點） | #D69B54 |
| Medical Blue（專業資訊、知識卡） | #477A9C |
| Text Dark（文字） | #26352F |
| 緊急紅（只用於「不舒服」與緊急） | #B5432A |

配色比例：70% 暖米白與淺色背景、20% 森林綠與鼠尾草綠、10% 醫療藍與暖金。

場景低彩度、角色高彩度，讓長輩一眼看到角色。

## 新增角色的檢查清單
- [ ] 以臺灣常見植物或在地文化為靈感
- [ ] 沿用花心臉、葉子手腳、同色系描邊
- [ ] 一句個性描述、三句台詞（其中一句是懷舊小問題）
- [ ] 不與任何既有遊戲、動畫角色相似；不使用球、捕捉等既有遊戲道具意象
- [ ] 在 46px 大小下仍能辨識

## 長輩友善
- 角色至少 46px、可點區域 48px 以上。
- 動畫緩慢、不閃爍，支援系統的「減少動態效果」。
- 文字不放在圖片上，一律另外顯示並可朗讀。
