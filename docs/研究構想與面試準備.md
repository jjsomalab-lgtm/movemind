# 心動力 AI｜研究構想與面試準備

## 一、一頁研究構想

**題目（暫定）**
結合循序活動與心理支持之數位介入應用於社區健康長者：可行性與初步效果之前導研究

**研究背景**
長者常因跌倒經驗或擔心跌倒而減少活動，形成「害怕—迴避」循環，導致身體功能退化、情緒低落與社會孤立。現有數位工具多單獨處理運動紀錄或聊天陪伴，較少同時兼顧運動安全與心理機制。

**研究問題**
1. 心動力 AI 對社區健康長者是否可行、可被接受（招募、留存、使用頻率、可用性）？
2. 使用前後，長者的運動自我效能、跌倒恐懼與孤寂感是否出現變化？
3. 在個人層次，每日活動與活動後心情之間是否存在關聯？

**研究設計**
單組前後測可行性研究，為期 8 週，搭配 APP 內每日活動與心情資料（生態瞬時評估）。不設對照組，因此不推論因果或宣稱療效。

**參與者**
高雄市社區照顧關懷據點之 65 歲以上健康長者，具基本自主活動能力、能在協助下使用智慧型手機。排除標準依首次健康篩選與醫師建議。

**測量工具（使用前確認中文版授權與信效度文獻）**

| 構念 | 工具 | 時間點 |
|---|---|---|
| 運動自我效能 | 運動自我效能量表（SEE，Resnick 編製，9 題） | 前測、後測 |
| 跌倒恐懼 | 簡版國際跌倒效能量表（Short FES-I，7 題） | 前測、後測 |
| 孤寂感 | 三題版 UCLA 孤寂感量表 | 前測、後測 |
| 憂鬱症狀（篩檢參考） | 老人憂鬱量表簡式版（GDS-15） | 前測、後測；分數偏高時依轉介流程處理 |
| 可用性 | 系統易用性量表或訪談 | 後測 |
| 日常歷程 | APP 內活動次數、活動前後心情、每週跌倒擔心度 | 每日、每週 |

**分析**
描述性統計呈現可行性指標；前後測以成對樣本檢定或無母數方法分析；每日資料以多層次模型探討個人內活動與心情的關聯。

**倫理**
送高雄醫學大學人體研究倫理審查；書面知情同意（大字、口語說明，可由家屬陪同）；量表由研究人員施測，APP 不自動判讀；建立憂鬱與自殺風險的轉介流程；資料去識別化。

**限制**
無對照組、樣本小、新奇效應、自陳偏誤、數位落差可能造成選樣偏誤。

## 二、面試時如何介紹這個作品（約 1 分鐘）

> 我在運動醫學系學習時發現，很多長輩不動，不是身體做不到，而是心裡不敢、不想。特別是跌倒過的長輩，會因為害怕而減少活動，結果身體更弱、更容易跌倒，也更孤單，這是一個害怕—迴避的循環。
>
> 我們做的心動力 AI，用運動醫學確保活動安全，再用心理學的設計幫長輩重建信心：從坐著的動作開始累積成功經驗，活動後讓長輩看見心情的變化，並每週追蹤他們對跌倒的擔心程度。
>
> 這個作品讓我很想進一步學習臨床心理學：如何更嚴謹地測量這些心理歷程，以及如何安全地處理長輩的情緒困擾。

## 三、可能被問到的問題與回答方向

| 問題 | 回答方向 |
|---|---|
| 如果長輩其實有憂鬱症怎麼辦？ | APP 不做診斷，定位是健康促進。心情只看趨勢、不判讀；心煩時提供 1925；研究中由研究人員施測 GDS，分數偏高依轉介流程處理。我了解這需要專業人員介入，這也是我想讀臨床心理的原因 |
| AI 說錯話怎麼辦？誰負責？ | 三道防線：自傷與身體緊急關鍵字先攔截並使用固定回覆，不經過 AI；AI 受系統提示詞限制；AI 回覆後再檢查診斷與用藥用語。上線前有測試清單，並訂使用條款與合作協議 |
| 長輩會不會依賴 AI、更孤立？ | 設計原則是「AI 是橋梁，不是替代」：聊天中定期鼓勵聯絡家人、去據點；社區合作任務把人帶回真實關係。這也是研究中要觀察的孤寂感指標 |
| 怎麼知道是 APP 有效，而不是新鮮感？ | 目前是可行性研究，不宣稱療效。新奇效應是限制之一，未來需要較長追蹤期與對照組設計 |
| 為什麼不直接轉介專業人員？ | 目標族群是健康長輩，需求是預防與健康促進，不是治療。有風險時才轉介；APP 讓專業資源用在最需要的人身上 |
| 這和一般運動 APP 差在哪？ | 處理的是「不敢動、不想動」的心理機制，而不只是記錄運動；而且安全規則由運動醫學把關 |
| 你在團隊中負責什麼？ | 如實說明自己的分工與貢獻（請依實際情況填寫） |
| 有沒有考慮文化因素？ | 華人長輩常以身體不適表達心理困擾，所以身體與心情在同一流程中被詢問；介面用臺灣口語，並規劃臺語語音 |
